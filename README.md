# Netflix-Clone

A responsive clone of the Netflix homepage built with HTML, CSS and a touch of JavaScript.  
```
    https://frontend-net-flix.netlify.app/
```


---

## 🚀 Project Overview  
* This project replicates the look and feel of the Netflix landing page (or similar streaming platform) using web fundamentals. 
* The focus is on layout, responsiveness, styling and basic interaction rather than backend functionality or actual streaming.

---

## 🎯 Features  
- Responsive design: Works across desktop, tablet and mobile viewports.  
- Clean, modern UI: Mimics Netflix’s colour scheme, typography and section layouts.  
- Navigation bar, hero banner, content rows/cards.  
- Basic interactivity: simple JavaScript to handle any needed UI behaviour  
- Built using only **HTML**, **CSS**, and **JavaScript** (no frameworks or libraries required).  
- Fully static — can be deployed easily on platforms like GitHub Pages, Vercel, Netlify etc.

---

## 🧰 Tech Stack  
- **HTML5**: Semantic structuring of content  
- **CSS3**: Flexbox/Grid, media queries, animations/transitions  
- **JavaScript**: Small scripts for UI behaviour    

---
